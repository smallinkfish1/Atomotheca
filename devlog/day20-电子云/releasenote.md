## 新增

- **电子云点云**：按 `C` 打开面板，选主量子数 `n`（1–6）和角向部分（s / p / d），
  以概率密度 `ρ = |R_nl(r)·Y(方向)|²` 撒点，每点一个像素。
- 补上了**径向函数** `R_nl(r)`（氢样，Z = 1）。第 19 天的形状只有角向部分，
  所以 `1s` / `2s` / `3s` 画出来是同一颗球；现在 `2s` 是「核心 + 空壳 + 外层」，
  `3s` 三层，`6s` 六层 —— 层数等于 `n − l + 1`。
- **相位染色**：`ψ > 0` 暖红、`ψ < 0` 冷蓝。径向/角向节面因此自动显形，
  不需要另画分界线。`3s` 的三层是红-蓝-红交替。
- 面板控件：点数（1 万–20 万）、点径（占云半径的百分比）、不透明度、`Resample`。
- 新增 `--dump-cloud [n形状]`：不开窗口打印采样自检与 ASCII 剖面。
  ```bash
  --dump-cloud            # 8 个默认轨道的摘要表
  --dump-cloud 3dz2       # 单个轨道：统计 + 一维径向剖面 + 二维剖面
  ```

## 改进

- **采样方式**：`|ψ|²` 可分离为 `R²(r)·|Y|²`，所以先反演径向 CDF 抽 `r`、
  再按 `|Y|²` 做球面拒绝采样。球的接受率 100%、p 33%、d 20%（实测 1.01 / 3.04 / 5.02 次每点）；
  若直接在立方体里拒绝，接受率只有 0.6%，20 万点要试三千多万次。
- **四类独立自检**（`--dump-cloud`），各自不共享假设：
  - `⟨r⟩`、`⟨r²⟩` 对闭式解 `(3n²−l(l+1))/2`、`n²(5n²+1−3l(l+1))/2`；
  - `⟨cos²θ⟩` 对球面数值积分（与径向无关）；
  - 径向节面位置对 `n − l − 1`（`3s` 实测 1.90 / 7.10 a₀，课本 1.902 / 7.098）；
  - 径向 CDF 的 Kolmogorov–Smirnov 偏差对 `1.36/√N`。
  10 个轨道实测偏差 0.0040–0.0088，全部在 0.0096 的上限之内。
- **渲染策略按点云特性重写**：不开排序（几十万点排不动），只做「深度测试开 + 深度写入关」、
  单点 alpha 恒定。点的数量密度已经正比于 ρ，再按 ρ 调亮度等于把密度平方一次，
  中心会糊成死白。
- **尺寸按 98% 半径归一**：`1s` 的 r98 是 3.8 a₀、`6s` 是 84.4 a₀，按真实比例画 `1s` 会变成一个点。
  真实半径在面板上以 a₀ 显示。
- **隐藏分子的判定统一**成 `moleculeHiddenForOrbitals()`，拾取 / 标签 / 不透明渲染三处共用，
  避免出现「画面里没有原子却能点中它」。

## 修复

- `--help` 里 `--dump-orbital` 的用法还写着 `[s|px|py|pz]`，第 19 天扩到 9 个形状后并未同步更新；
  已改为 `[形状]`。
- `--dump-cloud` 给了不存在的组合（`2d`、`1p`、`4f`、`7s`）会报错并列出约束，
  不会默默退回摘要表。

## 已知限制

- 只有氢样径向函数（Z = 1），没有屏蔽效应、没有相对论修正，也没有自旋与多电子反对称化。
  准确的标题是「氢样轨道的概率密度」，不是「这个元素的电子云」。
- 没有 f 轨道（l = 3）；点云固定在分子中心，不跟随单个原子。
- 沿轴观察时前后两瓣会投在同一片像素上，红 + 蓝混成紫色（体积渲染的固有现象）。
- 窗口内的点径、混合、遮挡观感尚未在真实 GPU 环境验证，只做到编译级与统计自检。
